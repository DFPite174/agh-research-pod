# 五模型定价方法与实现边界

实现入口为 `agh_pod.pricing.price(contract, model, steps=200, paths=10000, seed=42)`。返回的 `price`、`standard_error`、`diagnostics` 和 `method_status` 均可直接序列化为 JSON。所有结果都是模型计算，不能证明论文实证样本已经复现。研究门禁由上层证据流程负责。

方法说明依据郑振龙、竺添晟、陈蓉（2025）《中国可转债定价模型比较研究》正式公开正文印刷页 175–180，尤其式（2）–（4）及各模型边界：[期刊全文](https://nsd.pku.edu.cn/docs/20250227142007660959.pdf)。论文没有公开本次实现可直接调用的全部原始算法和合约历史，因此除解析 BS 的已声明模型外，其余状态均为 `IMPLEMENTED_APPROXIMATION`，不会返回“精确复现”。

## 输入合同

金额使用与面值相同的货币单位，股价/转股价使用同一单位，利率和波动率为十进制年化值，时间为自估值日起的年数。当前使用固定连续复利无风险利率、固定信用利差和固定股息收益率，历史收益曲线插值及信用利差插值应在上层完成。

`BondContract` 为不可变、仅限关键字构造的 dataclass，必填字段为 `spot`、`conversion_price`、`maturity`、`risk_free`、`credit_spread`、`volatility`。其他字段为：

| 字段 | 默认值 | 含义 |
|---|---|---|
| `face` | 100 | 面值，亦用于计算转股股数 `face/conversion_price` |
| `dividend_yield` | 0 | 连续股息收益率 |
| `coupons` | `()` | 按时间非递减排列的 `Coupon(time, amount)`；允许同日多笔 |
| `call` / `put` | `None` | `Trigger(ratio, window=30, required=15, start=0, end=inf, payment=100)` |
| `reset_floor` | `None` | 本次下修可用的固定合法最低转股价；不能高于初始转股价 |
| `history` | `()` | 最旧到最新的历史正股价格，**不包含**估值日 `spot` |

`Trigger.ratio` 是相对转股价的正股触发比例；`payment` 是赎回/回售全部结算款，若需包括应计利息应由使用者加入该款项。ZL 的 call 是窗口内不少于 required 天股价大于等于触发价；put 则小于等于触发价。窗口可跨条款生效日前，只有行权检查受 start/end 限制。估值日 spot 是首个当前观察值。缺少的历史观察值视为未满足条件，不会编造历史价格；诊断会明确提示。

`contract_from_dict()` 只接收上述字段，将嵌套对象转为 dataclass，拒绝未知字段。时间非负，票息不得晚于到期，票息金额非负，股价/面值/转股价/支付款/触发比例严格为正。数值必须有限，唯条款 `end` 可使用默认无穷大；JSON 中应省略无穷大的 end。信用利差、波动率和股息收益率不得为负；允许有限负无风险利率。

## 现金流及 BS

到期现金赎回额 `B_T = face + 到期日票息之和`。到期投资者取得 `max(face*S_T/K, B_T)`，股票转换和到期现金票息不能重复取得。到期前票息单独支付。因此 BS 使用风险中性股息调整后的股票价值 `A=face*S/K`：

```
V = B_T exp(-rT) + A exp(-qT) N(d1) - B_T exp(-rT) N(d2)
    + Σ_{0<t_i<T} coupon_i exp(-r t_i)
d1 = [ln(A/B_T)+(r-q+sigma²/2)T]/(sigma sqrt(T))
d2 = d1-sigma sqrt(T)
```

估值时点零期票息另外即时加入；T=0 直接支付到期较大额。sigma=0 使用确定性极限，避免除零。BS 不处理赎回、回售和下修，且按原文不用信用利差。

## TF、LYW、LW 三叉树

默认 200 步，使用固定转移概率 `1/6, 2/3, 1/6` 的重组三叉树 (Recombining Trinomial Tree)。对数跳距 `dx=sigma*sqrt(3dt)`，每步中心位移为 `(r-q)dt-ln(2/3+cosh(dx)/3)`，使离散条件股票期望与风险中性 GBM 一致。其扩散近似随步数收敛，但论文未披露的原树参数化不能假称已经完全一致。

到期股票转换部分记为权益，现金赎回部分记为现金；向后迭代时权益按 r 贴现，现金按 r+credit_spread 贴现。到期前票息进入现金部分。所有模型的自愿转股均按原文最后说明限制在到期；中间节点仅由相应条款边界产生股票结算。

- TF：赎回期内所有节点均允许发行人按 `max(call.payment, conversion_value)` 封顶，无需正股 n-of-m 条件；赎回是否执行仍取决于持有价值超过支付额。回售期按 put.payment 保底。强赎采用股票结算时现金部分为 0，采用现金结算时为支付款。原文对 `U=0` 的简写不能独立处理现金强赎情形，此处按实际支付种类分拆。
- LYW：在赎回期，持有价值不低于 `max(face*call.ratio, call.payment)` 时封顶为 `face*call.ratio`；其余节点使用原文 `max(conversion_value, cash_component)` 边界。回售期若 `put.payment >= max(face*put.ratio, cash_component)`，则按 `max(conversion_value, put.payment)` 保底。此为论文的价值边界代理，不能视作实际滚动股价条件。
- LW：其余与 LYW 相同，把赎回比例乘 1.079，回售比例乘 0.86。这是论文的经验调整，并非实测本次数据得到的参数。

非网格日票息移至紧随其后的网格点，并按对应现金贴现率补偿时间差，因此无条款条件下票息现值精确；存在条款时现金流先后顺序会有最多一个 dt 的离散误差，诊断给出上限。提前终止支付额不另叠加同日票息。树的标准误为 0 只表示确定性算法，不表示离散误差或模型误差为 0。

## ZL 逐日蒙特卡洛

每年 252 个交易日，区间数为 `ceil(252*T)`，最后一步仍严格落在 T，所有路径以固定种子独立 GBM 增量生成。每日维护 call/put 布尔滚动窗口及命中数，不用树节点的当前价值替代历史正股路径。

在到期日前，先判断强赎，命中即支付 `max(conversion_value, call.payment)`，终止该路径；然后处理仍存续路径的回售。存在可用 reset_floor 时：

1. 若当期 BS 值已至少等于回售款，不需下修或回售。
2. 若 BS 在 floor 处仍低于回售款，立即支付回售款并终止路径。
3. 否则在 `[reset_floor, 当前K]` 对转股价做 50 次二分，取满足 BS 值不少于回售款的最高 K，更新该路径转股价并继续模拟。

若未提供 reset_floor，仍先检查当前 BS 值：已经不低于回售款时，无需下修，不执行回售。只有当前 BS 低于回售款、确实需要下修的触发路径才直接现金结算；诊断说明这是缺少下修约束数据时的明确替代情景，不能将其称为完整 ZL 下修定价。静态 floor 不能替代真实发行条款中的净资产/历史均价约束，应由真实数据配方给出适当时点约束并扩展模型。

历史观察日缺少真实转股价变化，因此历史资格按初始 K 计算；下修后保留过去观察日已记录的资格，未来按新 K 计算。当天回售引起下修后的强赎从下一观察日重新检查。到期当日优先执行到期赎回/转股，不再处理可选条款。上述先后顺序及历史口径都在 diagnostics 登记；论文未充分披露，需在真实合同历史核验后进一步校准。

所有 ZL 支付按无风险利率贴现，信用利差不用于此模型，与论文相同。存续票息、提前终止款和到期款均按发生时间折现；提前终止后不再收到未来票息。`standard_error` 是路径现值样本标准差除以 sqrt(paths)，`confidence_95` 为正态近似区间，仅覆盖抽样误差，不含离散误差、条款缺失和模型误设。

## 计算预算与验证

steps 为 1–2000，paths 为 2–200000，种子为非负整数。ZL 单次不超过 5000 万个路径日及 2000 万个滚动布尔标记，限制工作台请求的时间和内存。合同数值域限制 T<=100 年、sigma<=5、|r|<=1、credit_spread<=1；过大树范围或浮点溢出明确拒绝，不返回 NaN/Infinity。树范围限制还避免过大的中间股票指数值。

测试包含独立 BS 公式、股息调整、TF 现金/权益独立终值积分、零波动/到期/票息手算、非网格票息现值、无条款树收敛、MC 种子重复及解析值区间、历史触发及窗口过期、条款生效期、赎回优先、下修可行/不可行，以及负例与计算预算。**不以人为设置五模型的价格排名作为验证。** 这些是数学/工程证据，不能代替 Wind/CSMAR 样本的独立实证复跑。
