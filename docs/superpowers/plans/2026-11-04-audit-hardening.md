# 全面审查与可靠性改进计划

基线e4e8c95。用户授权全面分析并继续改进，沿用单用户、固定受审查配方与研究/交易分离边界。

1. 复现交付包可省略附件、反馈非原子写入、非法/重复CSV、非结构化模型响应等问题。
2. 加强交付校验：审批哈希、原始数据、可重跑manifest、来源附件及结果快照一致；接收时对照数据库保存的manifest；反馈和状态在同一事务提交。
3. 量化输入：有界字节读取、原始列名检查、日期规范；可选频率与可用时点字段检查，未提供时明确PIT未核实；保留旧数据兼容。
4. 分析持久化：集中准备证据并记录输入哈希、预算、状态和输出；CLI/API共用，未知配置保持NOT_RUN。
5. 首页使用摘要而非嵌入完整预测结果，避免任务增多后巨量HTML。
6. 完整测试、10案例回归、构建/安装检查和独立审阅；输出审查问题表、已修复与待建设项，再同步现有GitHub分支。
